## 🧩 Projetos em Destaque

- 🧠 **Billumy** — Assistente de IA com Ollama, modelos customizados, embeddings e arquitetura segura com Nginx + NMS.  
- 🧭 **Noeris** — Frontend em React para interação com múltiplos LLMs via classificador inteligente (Maestro).  
- ⚙️ **NoerisCore** — Backend em Django (baseado no ArmoredDjango) para orquestração de modelos, APIs e fluxos de IA.  
- 🖥️ **NMS (Nubo Management System)** — Painel administrativo para gerenciamento de recursos dinâmicos e feature flags.  
- 🔧 **NMSCore** — Backend em Go responsável por decisões rápidas, cache e controle de acesso do NMS.  
- 📡 **NuboPulse** — Backend de observabilidade e orquestração de infraestrutura e containers.  
- 🎛️ **NuboPanel** — Frontend em React + Vite para visualização e gestão da infraestrutura monitorada pelo NuboPulse.  
- 🛡️ **ArmoredDjango** — Template open source em Django com autenticação, RBAC, Docker, testes e boas práticas de produção.  

Também sou autor de pacotes publicados no **PyPI**, como o [MaterialDash](https://pypi.org/project/materialdash/).
